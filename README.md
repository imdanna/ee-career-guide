# 전기전자

대학생청소년 AI 멘토링의 고1 멘티가 전자·전기공학 산업을 넓게 살펴보고, 이해한 원리를 자기 말로 설명하는 발표 주제를 고르는 웹사이트입니다. 근거 확인 기준일은 **2026년 10월 26일**입니다.

## 웹사이트와 Notion 중 선택

| 기준 | Render 웹사이트 | Notion 페이지 |
|---|---|---|
| 학생의 주제 탐색 | 관심 산업·학년·검색을 함께 적용 | 문서와 데이터베이스 중심 |
| 화면 구성 | 한국어 읽기 흐름과 모바일 화면을 직접 설계 | 정해진 문서 구성으로 빠르게 작성 |
| 내용 수정 | 파일 수정 후 배포 | 문서에서 바로 수정 |
| 이번 목적 | **추천: 여러 주제를 비교하며 고르는 안내 사이트** | 멘토 개인의 메모·운영 기록에 적합 |

학생용 안내는 웹사이트로, 수시로 바뀌는 멘토 메모는 Notion으로 관리하면 역할을 나누기 쉽습니다. Notion 페이지는 별도로 생성하지 않았습니다.

## 학생이 사용하는 순서

1. ‘산업 흐름’에서 각 분야를 펼쳐 주목받는 이유, 한계, 진로 연결과 근거를 읽습니다.
2. ‘발표 주제’에서 산업·학년을 선택하거나 검색합니다. 첫 화면은 고1 주제 6개입니다.
3. 주제를 펼쳐 탐구 질문, 핵심 원리, 기술 비교, 발표 포인트와 차별화 방향을 읽습니다.
4. ‘이 주제로 10분 발표안 보기’를 누르면 해당 주제의 시간 배분과 설명 방향이 나타납니다.
5. ‘발표안 인쇄’로 선택한 발표안과 출처 주소를 출력할 수 있습니다.

학년은 권장 난이도이며 공식 교육과정이나 세특 평가 기준을 뜻하지 않습니다. 학교 수업과 실제 이해 수준에 맞춰 조정합니다.

## 주제 구성

| 산업 | 고1 · 개념 이해 | 고2 · 원리 비교 | 고3 · 시스템 판단 |
|---|---|---|---|
| AI 데이터센터 | 냉각장치가 필요한 이유 | PUE와 총 에너지 | 온디바이스와 클라우드 |
| 로봇·자율주행 | 카메라와 라이다 | 피드백 제어 | 규칙 기반 제어와 피지컬 AI |
| 전력망·ESS | 낮의 전기를 밤에 쓰기 | 고전압 송전과 손실 | 망 증설·ESS·수요 반응 |
| 반도체 | CPU와 GPU | HBM과 데이터 병목 | 미세화와 칩렛·패키징 |
| 전기차·배터리 | 배터리 용량의 균형 | 급속충전의 한계 | LFP와 NMC |
| 통신·6G | 속도와 지연 | 주파수와 연결 범위 | 통신·센싱 통합 |

각 주제는 문헌과 근거를 설명·비교하는 발표로 구성했습니다. 회생제동에 편중하지 않고 6개 산업을 같은 비중으로 다룹니다.

## 공통 10분 구성

| 시간 | 흐름 | 설명할 내용 |
|---|---|---|
| 0:00–1:00 | 탐구 동기 | 생활 속 궁금증과 질문 하나 |
| 1:00–3:30 | 원리 | 핵심 개념 2~3개, 개념 그림 |
| 3:30–6:00 | 기술 비교 | 동일 조건의 비교 기준 3개 |
| 6:00–8:30 | 한계·전망 | 조건·제약과 사실/전망 구분 |
| 8:30–10:00 | 결론 | 질문의 답, 달라진 생각, 다음 질문 |

질의응답 시간은 별도입니다. 학생에게 완성된 답을 암기시키기보다 질문을 좁히고 비교 기준을 스스로 선택하게 하는 것을 권합니다.

## 근거 관리

`dist/content.js`에 14개 출처와 18개 주제가 들어 있습니다. 각 산업과 주제에서 관련 원문으로 이동할 수 있습니다. 원리 해설용 과거 자료와 2026년 산업 근거를 구분했습니다.

- [IEA, Energy and AI 갱신 보고서](https://www.iea.org/reports/key-questions-on-energy-and-ai): 2026-04-16. 데이터센터 전력의 관측값과 전망을 구분.
- [IFR, World Robotics 2026 관련 보고](https://ifr.org/ifr-press-releases/news/presidents-report-by-jane-heffner-3-2026): 2026-09-24. 산업용 로봇 통계의 범위를 명시.
- [IEA, 전기차 7월 갱신 자료](https://www.iea.org/reports/electric-car-markets-in-a-time-of-uncertainty/executive-summary): 2026-07-30. 5월 연간 전망 대신 상반기 집계와 갱신 전망을 반영.
- [ITU-R 진행 현황](https://www.itu.int/en/ITU-R/study-groups/rsg5/rwp5d/pages/imt.aspx): 2026년 10월 기준. 12월 예정 승인을 완료로 표현하지 않음.
- [SK hynix 메모리 기술 해설](https://news.skhynix.com/en/ai-ecosystem-series-ep4/): 2026-10-21. 제조사 자료라는 성격을 명시.

원문을 그대로 옮기지 않고 교육적으로 재구성했습니다. 수치·기간·단위·대상 지역을 유지합니다. 이후 발표는 자동 반영되지 않습니다.

## 적용한 스킬과 디자인 참고

- **Ponytail:** 이 환경에서 사용 가능함을 확인했습니다. 별도 프레임워크·설치 패키지·데이터베이스 없이 HTML/CSS/JavaScript로 구현했습니다.
- **[Impeccable](https://github.com/pbakaus/impeccable):** README, 현재 SKILL, Read 모드, new-work와 craft-floor 지침 및 라이선스를 검토했습니다. 읽기 중심의 위계, 절제된 색, 점진적 공개, 키보드 포커스, 대비와 모바일 구성을 참고했습니다.
- Impeccable은 완성된 화면 템플릿이 아닙니다. 저장소의 코드를 복사하거나 실행 도구를 설치하지 않았으며, 자동 점검기를 실행했다고 주장하지 않습니다. 디자인 원칙을 참고해 독자적으로 구현했습니다.
- Sites 스킬의 정적 구현·미리보기 흐름과 Render 스킬의 계정 확인·배포 검증 흐름을 사용했습니다. 호스팅은 요청한 Render를 대상으로 합니다.

## Chat에서 Work로 이어가기

OpenAI 공식 안내는 제품 선택에서 **ChatGPT → Work**를 고르도록 설명합니다. 데스크톱에서는 계정에 따라 로컬 작업을 선택할 수 있습니다. 이 채팅에서는 참조된 이전 대화의 맥락을 읽고 실제 파일 제작을 진행했습니다. 화면의 모드 스위치를 자동으로 바꿨다고 주장하지 않습니다.

다른 Work 채팅에서 이어갈 때는 사이트 주소 또는 이 폴더를 열고 “현재 전기전자 사이트를 이어서 수정해 줘”라고 요청하면 됩니다. 새 채팅이 이전 대화와 로컬 폴더를 자동으로 모두 이어받는다고 가정하지 마세요.

공식 안내: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt)

## 로컬 열기와 수정

`dist/index.html`을 브라우저에서 열면 동작합니다. 외부 글꼴·분석기·광고·로그인·학생 정보 수집이 없습니다. 원문 출처를 열 때만 외부 사이트로 이동합니다.

내용은 `dist/content.js`, 화면은 `dist/styles.css`, 탐색 동작은 `dist/app.js`에서 수정합니다.

```text
node verify.mjs
python -m http.server 8765 --directory dist --bind 127.0.0.1
```

## Render 설정

사용자가 확인한 작업 공간: **단아's workspace**. 새 GitHub 저장소로 분리하는 방향을 확인했습니다.

- 서비스 종류: Static Site
- Build Command: `true`
- Publish Directory: `dist`
- 추가 서버·데이터베이스·비밀키: 필요 없음

`render.yaml`은 공식 JSON Schema로 검증했습니다. Render CLI가 설치되어 있지 않아 CLI 검증은 실행하지 않았습니다. 실제 배포 결과는 `DEPLOYMENT.md`에 기록합니다.

참고: [Render Static Sites](https://render.com/docs/static-sites), [Blueprint 사양](https://render.com/docs/blueprint-spec)
